## 🚀 Install

```bash
curl -L https://raw.githubusercontent.com/neuralmint/fileorg/main/fileorg -o /usr/local/bin/fileorg
chmod +x /usr/local/bin/fileorg
```

## 📋 Commands

| Command | Description |
|---------|-------------|
| `fileorg type <dir>` | Group files by type |
| `fileorg date <dir>` | Group by modification date |
| `fileorg size <dir>` | Show largest files |
| `fileorg dupes <dir>` | Find duplicate files |
| `fileorg empty <dir>` | Find empty files & dirs |
| `fileorg tree <dir>` | Directory tree view |
| `fileorg ext <dir> <ext>` | Filter by extension |
