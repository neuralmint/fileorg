# Fileorg

CLI tool for the terminal. Zero dependencies.

```bash
curl -L https://raw.githubusercontent.com/neuralmint/fileorg/main/fileorg -o /usr/local/bin/fileorg
chmod +x /usr/local/bin/fileorg
```

Run `fileorg help` for usage.
